PrintPad




Your phone must be on the same WiFi network as the ESP32 printer bridge. If "Print" fails with a network/mixed-content error, see the note below.

This page is served over HTTPS (GitHub Pages), but the printer bridge only speaks plain HTTP on your local network. Some mobile browsers block that call for security reasons ("mixed content"). If printing fails here, open http://<bridge address>/ directly in your phone's browser instead of this github.io link — loading the tool from the bridge's own address avoids the HTTPS/HTTP mismatch entirely.
